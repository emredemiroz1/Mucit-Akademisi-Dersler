# 2025-2026 Donemi

Bu klasorde 2025-2026 doneminde derste yazdigimiz eski kodlar bulunur.

## Bu klasorde neler var?

- Arduino baslangic dersleri
- LED, buzzer ve potansiyometre ornekleri
- Motor kontrol kodlari
- Cizgi izleyen robot kodlari
- Engelden kacan robot kodlari
- Sumo ve yarisma denemeleri

## Nasil calismaliyim?

1. Once `Arduino_Kodlari` klasorunu acin.
2. Ders veya proje adina gore klasoru secin.
3. Klasorun icindeki `.ino` dosyasini Arduino IDE ile acin.
4. Kodu yuklemeden once ogretmeninizin anlattigi baglantilari kontrol edin.

Bu bolum eski donem arsividir. Yeni kodlar `2026-2027` klasorune eklenecek.
