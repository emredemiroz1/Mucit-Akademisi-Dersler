# 99 - Eski Kod Notlari

Bu klasor, 2025-2026 donemindeki cizgi izleyen kodlarindan alinan fikirleri toplamak icindir.

## Korunan teknik fikirler

- 8 analog QTR sensor kullanimi: A0-A7.
- Siyah cizgi icin esik degeri ile karar verme.
- PID'li modelde orta nokta olarak `3500` kullanma.
- Kesisim, keskin donus ve cizgi kaybetme durumlarini sonradan ayrica gelistirme.

## Yeni ROBOMER standardi

- Sag motor: D5, D6
- Sol motor: D9, D10
- Buzzer: D3
- Buton: D7
- Anahtar: D4
- LED'ler: D11, D12, D13

Bu klasordeki notlar, yeni profesyonel modeller gelistikce guncellenebilir.
