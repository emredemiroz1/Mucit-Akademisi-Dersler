# 03 - Fanli PID'siz Cizgi Izleyen

Bu model fanli robot taslaklari icindir. PID kullanmaz; sensor bolgelerine gore karar verir.

## Fan notu

Fan cikisi taslak olarak `D2` secildi. Eger sensor kartinizda emitter pini de `D2` kullaniyorsa fan icin farkli bir cikis secin.

Fanli robotta once dusuk hizla deneyin. Fan zemine fazla basarsa robot donuslerde zorlanabilir.
