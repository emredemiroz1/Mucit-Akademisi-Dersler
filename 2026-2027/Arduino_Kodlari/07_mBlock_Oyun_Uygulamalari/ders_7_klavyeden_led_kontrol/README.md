# Ders 7 - Klavyeden LED Kontrol

Bu ornekte bilgisayardan seri ekran ile `r`, `y`, `g` harfleri gondererek LED'leri kontrol ediyoruz.

ROBOMER anakartinda LED'ler sadece 11, 12 ve 13 numarali pinlerdedir.

## Komutlar

- `r`: D11 LED yanar
- `y`: D12 LED yanar
- `g`: D13 LED yanar
- `s`: Tum LED'ler soner
