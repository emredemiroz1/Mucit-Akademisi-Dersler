# 09 - Cizgi Sensoru Uygulamalari

Bu kategori cizgi sensoru ve cizgi izleyen robot calismalari icindir.

## Bu bolumde neler olacak?

- Sensor degeri okuma
- Siyah ve beyaz zemini ayirt etme
- Cizgide durma
- Iki cizgi arasinda gitme
- Cizgi izleyen robot algoritmasi

Yeni cizgi sensoru kodlari bu klasore eklenecek.

## Eklenen ornekler

- `ders_9_cizgi_sensoru_okuma`: Cizgi sensoru degerini seri ekranda gosterir.
